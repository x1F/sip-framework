## 3.4.0 - 2024-07-01

### ⭐ Features
- Added ChecksumHelper class for adapter fingerprinting in SIP Cloud [#256](https://github.com/IKOR-GmbH/sip-framework/pull/256) by [MartinBuchheim](https://github.com/MartinBuchheim)
- Added API to add custom processor extensions to connectors [#266](https://github.com/IKOR-GmbH/sip-framework/pull/266) by [MartinBuchheim](https://github.com/MartinBuchheim)
- Add possibility to define scenario and connector level configuration. Add hooks to define connector level exception handlers. [#265](https://github.com/IKOR-GmbH/sip-framework/pull/265) by [Nemikor](https://github.com/Nemikor)
- Add missing documentation for integration scenario orchestration. The orchestration is explained with two simple code snippets. [#261](https://github.com/IKOR-GmbH/sip-framework/pull/261) by [malte-westendorf-ikor](https://github.com/malte-westendorf-ikor)
- Add support for doWhile and forLoop loops in scenario and process orchestration. [#254](https://github.com/IKOR-GmbH/sip-framework/pull/254) by [Nemikor](https://github.com/Nemikor)
- Added a possibility for a REST demo adapter to be generated by archetype. It uses Nobel Prize API to and demonstrates common SIP Features. [#257](https://github.com/IKOR-GmbH/sip-framework/pull/257) by [Nemikor](https://github.com/Nemikor)
- Improved handling / mapping of query- and path-parameters for inbound REST connectors [#258](https://github.com/IKOR-GmbH/sip-framework/pull/258) by [MartinBuchheim](https://github.com/MartinBuchheim)
- Add support for dynamic endpoints in outbound connectors. The type of endpoint will be determined automatically based on presence of placeholders in uri. [#259](https://github.com/IKOR-GmbH/sip-framework/pull/259) by [Nemikor](https://github.com/Nemikor)
- Spring Boot updated to version 3.2.7 [#267](https://github.com/IKOR-GmbH/sip-framework/pull/267) by [MartinBuchheim](https://github.com/MartinBuchheim)

### 🐞 Bugfixes
- Bumped spring boot and CXF versions to resolve security issues. [#252](https://github.com/IKOR-GmbH/sip-framework/pull/252) by [Nemikor](https://github.com/Nemikor)
- Change adapter-routes actuator endpoint to adapterroutes and update the version of adapter-routes feature. [#260](https://github.com/IKOR-GmbH/sip-framework/pull/260) by [Nemikor](https://github.com/Nemikor)
- Improved error message when an exception is triggered from a method-based connector processor [#268](https://github.com/IKOR-GmbH/sip-framework/pull/268) by [MartinBuchheim](https://github.com/MartinBuchheim)
- Fix an issue where REST headers were not taken from test case definition. Enable resolving path parameters of rest endpoints using headers. [#264](https://github.com/IKOR-GmbH/sip-framework/pull/264) by [Nemikor](https://github.com/Nemikor)
- Remove SIPDefaultErrorHandler as it might cause issues. [#263](https://github.com/IKOR-GmbH/sip-framework/pull/263) by [Nemikor](https://github.com/Nemikor)

### 📔 Documentation
- Add missing brackets in code example. [#262](https://github.com/IKOR-GmbH/sip-framework/pull/262) by [Nemikor](https://github.com/Nemikor)
