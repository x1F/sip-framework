## 3.6.2 - 2025-03-27

- Disable CSRF by default in SOAP configuration. [#285](https://github.com/IKOR-GmbH/sip-framework/pull/285) by [Nemikor](https://github.com/Nemikor)
- Prevent NPE when context path is not set in configuration. [#281](https://github.com/IKOR-GmbH/sip-framework/pull/281) by [Nemikor](https://github.com/Nemikor)
- Update dependencies that contain vulnerabilities [#287](https://github.com/IKOR-GmbH/sip-framework/pull/287) by [Nemikor](https://github.com/Nemikor)
- Forbid usage of multiple REST DSL verbs for different HTTP methods in a single Rest inbound connector. [#284](https://github.com/IKOR-GmbH/sip-framework/pull/284) by [Nemikor](https://github.com/Nemikor)
- Remove usage of deprecated methods from spring security and use up-to-date ones. [#286](https://github.com/IKOR-GmbH/sip-framework/pull/286) by [Nemikor](https://github.com/Nemikor)
- Add possibility to configure additional parameters in SOAP endpoints, like DataFormat [#283](https://github.com/IKOR-GmbH/sip-framework/pull/283) by [Nemikor](https://github.com/Nemikor)
