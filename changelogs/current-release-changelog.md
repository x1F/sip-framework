## 4.0.0 - 2025-08-15

### 🚀 Major Changes
- Update SIP Framework to v4 major release [#279](https://github.com/IKOR-GmbH/sip-framework/pull/279) by [MartinBuchheim](https://github.com/MartinBuchheim)

### ⭐ Features
- New API to extend the integration flow within connectors via Camel DSL [#283](https://github.com/IKOR-GmbH/sip-framework/pull/283) by [MartinBuchheim](https://github.com/MartinBuchheim)
- Build process improvement: allow manually given release version as an option to automatic computation [#288](https://github.com/IKOR-GmbH/sip-framework/pull/288) by [MartinBuchheim](https://github.com/MartinBuchheim)
- The example batch test provided by the archetype has been removed. Additional enhancements have been implemented to improve maintainability and functionality. [#304](https://github.com/IKOR-GmbH/sip-framework/pull/304) by [malte-westendorf-ikor](https://github.com/malte-westendorf-ikor)
- Remove SIP Middle component [#294](https://github.com/IKOR-GmbH/sip-framework/pull/294) by [Nemikor](https://github.com/Nemikor)
- Moved artifacts and packages from 'de.ikor.sip' to 'one.x1f.sip' namespace [#301](https://github.com/IKOR-GmbH/sip-framework/pull/301) by [MartinBuchheim](https://github.com/MartinBuchheim)
- The former code formatter fmt from Spotify has been replaced with spotless. [#296](https://github.com/IKOR-GmbH/sip-framework/pull/296) by [malte-westendorf-ikor](https://github.com/malte-westendorf-ikor)
- Split and parallel split were added to Process Orchestration DSL [#291](https://github.com/IKOR-GmbH/sip-framework/pull/291) by [Nemikor](https://github.com/Nemikor)
- Add useSipCloudFramework property to archetype which can enable SIP Cloud Framework [#297](https://github.com/IKOR-GmbH/sip-framework/pull/297) by [Nemikor](https://github.com/Nemikor)
- Update Apache Camel to 4.10.6, Spring Boot to 3.4.8 and other minor ones [#294](https://github.com/IKOR-GmbH/sip-framework/pull/294) by [Nemikor](https://github.com/Nemikor)
- Removed actuator endpoint for declarative structure [#293](https://github.com/IKOR-GmbH/sip-framework/pull/293) by [MartinBuchheim](https://github.com/MartinBuchheim)

### 🐞 Bugfixes
- Rename annonation package to annotation [#298](https://github.com/IKOR-GmbH/sip-framework/pull/298) by [Nemikor](https://github.com/Nemikor)
- Fix exchange handling when executing testkit tests [#289](https://github.com/IKOR-GmbH/sip-framework/pull/289) by [nemikor](https://github.com/nemikor)
- Updated and improved GitHub automated build & release process [#302](https://github.com/IKOR-GmbH/sip-framework/pull/302) by [MartinBuchheim](https://github.com/MartinBuchheim)

### 📔 Documentation
- A complete list of SIP application properties has been added. [#299](https://github.com/IKOR-GmbH/sip-framework/pull/299) by [malte-westendorf-ikor](https://github.com/malte-westendorf-ikor)
- Added instructions for upgrading adapters from 3.6.2 to 4.0.0 [#303](https://github.com/IKOR-GmbH/sip-framework/pull/303) by [MartinBuchheim](https://github.com/MartinBuchheim)
