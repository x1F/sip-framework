## 4.1.0 - 2025-11-05

### ⭐ Features
- Add an option to include Jib maven plugin for creating docker images in SIP archetype [#310](https://github.com/IKOR-GmbH/sip-framework/pull/310) by [Nemikor](https://github.com/Nemikor)
- Add useSipSecurity property to SIP Archetype which will include sip-security dependency in the generated adapter. [#314](https://github.com/IKOR-GmbH/sip-framework/pull/314) by [Nemikor](https://github.com/Nemikor)
- Use dynamically read api properties in application.yaml generated by SIP archetype. [#312](https://github.com/IKOR-GmbH/sip-framework/pull/312) by [Nemikor](https://github.com/Nemikor)
- Prevent loading TestKit beans in runtime [#313](https://github.com/IKOR-GmbH/sip-framework/pull/313) by [Nemikor](https://github.com/Nemikor)
- Add a new goal declarative-structure-check in SIP Maven plugin, which checks whether declarative structure classes are valid. [#316](https://github.com/IKOR-GmbH/sip-framework/pull/316) by [Nemikor](https://github.com/Nemikor)
